# Magnas Hiring Pilot

Frontend for maintaining a professional profile, configuring multiple job searches, and reviewing job matches.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

Profile data and job search configurations are currently stored in browser `localStorage`. The application has no connected backend or job provider in this repository. Job listing and matching score integrations remain unavailable until a provider is connected.
